# 扩展使用说明（Chrome / Edge）

1. 打开 chrome://extensions，开启开发者模式，加载此文件夹；升级文件后点击“重新加载”。
2. 打开扩展设置，填入 NAS 地址（例如 http://192.168.192.2:8765），保存并允许访问该地址，再测试连接。
3. 浏览器登录 x.com，打开书签页（历史页请选择“书签”），再点击“自动采集历史书签”；日常更新可用“快速同步”。登录失效时页面会保留，自动采集暂停；登录后再次手动同步。
4. 点击“自动采集历史书签”后无需手动下拉。进度面板显示捕获数量、滚动轮数、运行时间和待传数量，可停止并保留已捕获内容。关闭弹窗不影响采集，请保持 X 书签页打开。每轮最多 300 轮；持续无新增会停止并提示可能不完整，只有 X 返回终止信号才提示列表结束。“快速同步”及定时任务只采集最近内容。

浏览器需运行且保持 X 登录态。扩展只监听书签数据，不替用户发帖或改收藏。

采集内容先保存到浏览器本地，NAS 不通时显示待传数量，每 5 分钟尝试补传。每批最多 100 条，收到 NAS 的 ok:true 确认后才删除本地对应批次；服务端升级为本项目当前代码后，元数据与下载任务在同一事务提交。NAS 接收成功不表示媒体已下载。

队列不会静默丢弃超过 2000 条的数据，但仍受浏览器存储配额限制；配额不足会报错，保留采集页面。卸载扩展/清理浏览器数据会删除待传队列；改 NAS 地址会向新地址投递现有待传数据。

支持按登录账户分库，仅用于可信私有网络；没有独立配对鉴权，NAS 无法脱离浏览器登录页面采集。真实 X 改版、登录验证或限流仍可能导致采集失败。更新扩展后重新加载并刷新 X 页面。

0.2.1：兼容 /i/history 的书签标签；设置页可查看最近任务记录。升级后刷新已打开的 X 页面再同步。

0.2.3：立即同步复用已有书签页，优先当前活动页；同步不会新建或关闭标签页。定时采集仅在已有书签页时执行，待传队列仍独立补传。升级后刷新 X 页面。

0.2.4：按当前登录的 @用户名绑定捕获和待传队列，切换账户不改变旧数据归属。必须先升级 NAS 到 0.3.1，再重新加载扩展并刷新 X 页面。账户无法识别时不会自动归入旧库。

0.2.5：在已登录的 X 页面识别并报告本人 @用户名，不需要进入书签页或点击同步。识别结果在 NAS 旧数据归属面板中读取；离线时重试，迁移仍需预览并明确选择目标账户。升级后刷新 X 页面。


## 0.4.0 安全配对

需搭配 NAS 0.6.0。先在 NAS 管理页登录 → 连接与配对 → 生成配对码，再在扩展设置填写 NAS 地址、浏览器名称及配对码。配对码 5 分钟有效且只能使用一次。凭据只保存在当前浏览器并绑定该 NAS 地址，不经 Chrome 账户同步；NAS 撤销连接后待传队列保留，重新配对即可补传。升级扩展后必须重新加载并刷新 X 页面。
