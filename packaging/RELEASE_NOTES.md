X Bookmark Sync 0.5.0 / 扩展 0.3.0

- NAS 新增单条/批量删除及回收站恢复；文件保留，不释放磁盘空间，再次同步不会自动恢复已删除书签。
- 新增下载状态筛选，卡片/列表/媒体预览切换。
- 插件自动滚动采集，显示捕获数量、滚动轮数、耗时和待传数量，可停止。
- 修复虚拟列表高度不变导致过早停止、实时补传覆盖采集状态的问题。
- 区分列表结束、无新增暂停、达到上限和手动停止，不承诺未知总量的完成百分比。

使用独立 FPK 升级 NAS，保留配置和数据。更新插件后重新加载并刷新 X 页面。自动采集需保持已登录的书签页打开；定时任务使用快速同步。仅用于可信私有网络。详见 README 安装及使用教程。
