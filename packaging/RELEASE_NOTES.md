# 0.6.1

- 可信局域网通过 IP 地址打开管理页默认免登录，安装密码改为可选；已有密码保护在升级后保持。
- 扩展 0.4.1 填写 NAS 地址后，在 NAS 页面确认一次即可连接，无需复制密钥或配对码。
- 连接请求 5 分钟有效，凭据只由原请求浏览器领取，扩展权限保持受限；支持超时重试和撤销。
- 已连接浏览器、待传队列和同步历史在升级后保留，配对码作为高级备用方式。
- 高级设置支持开启局域网密码保护，立即撤销旧管理会话并保留扩展连接。

免登录适用于个人可信局域网，不应直接暴露到公网。程序、配置和媒体存储路径不变。

# 0.6.0 开发候选版本

- 管理页面使用不允许跨域读取的一次性操作凭据，修复来源请求头改写导致删除、恢复和重试被误拒绝的问题。
- 新增管理密码登录、一次性扩展配对、连接撤销与本机恢复访问。扩展权限只允许提交及同步统计。
- 飞牛安装向导可设置管理密码；既有配置和数据保留。
- 浏览器补传与本地入队分离，启动后立即补传，并明确未完成采集。
- 新增存储诊断、脱敏导出、数据库快照与独立目录恢复，以及实际打包产物的生命周期测试。
- 回收站可彻底清理所选书签及本地文件，保护共享引用并保留去重标记；清理失败后台重试。
- 按账户设置下载范围、暂停和媒体预算，达到预算后暂停新任务，正在下载的任务可完成。

升级须知：同时更新扩展至 0.4.0，重新加载并刷新 X 页面，随后配对 NAS。旧扩展的匿名上传会被拒绝，待传内容保留。默认数据位置使用所选存储卷，原自定义路径不变。

此版本仍需完成真实飞牛升级恢复、浏览器长期内测，不代表发布验收清单已全部通过。
