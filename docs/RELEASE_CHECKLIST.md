# 发布前验收

当前开发改动不等于已经通过 NAS 验收，也不等于已正式发布。每次发布填写版本、测试环境和证据；未完成的 P0 不得标记完成。

## 本轮已实现，等待安装包集成验证

- 上传网络等待与本地持久化队列分离；精确确认上传内容，不删除上传期间更新的捕获数据。
- 浏览器安装/启动时立即补传，恢复中断状态；未确认历史采集完整时明确提示。
- NAS 诊断及脱敏导出（存储可写、剩余空间、版本；不探测 X 登录）。
- 私有元数据快照及校验；包含配置和所有账户数据库，不包含媒体文件。
- FPK 打包后解包并运行生命周期测试，保留合成账户数据与媒体标记。
- 应用启动验证 HTTP 版本及媒体目录；独立部署检查可发现安装工具跳过升级。

## P0：阻断正式推广

- [ ] 飞牛应用中心：干净安装、旧版升级、失败恢复，记录系统版本及操作步骤。不得把 install-fpk 返回 0 当成升级成功，也不得用手动覆盖程序文件代替此验收。
- [ ] 首次连接向导：已实现飞牛管理密码输入、网页登录/配对、扩展设置引导，待真实安装包和浏览器首次同步验收。
- [ ] 管理界面与扩展鉴权：实现会话、一次性配对、凭据撤销、本机恢复和安装密码，自动化权限测试通过，待实际部署验收。
- [ ] NAS 离线、扩展更新、浏览器重启、重复点击和账号切换的真实浏览器验收。
- [ ] X 限流、登录失效、列表停滞、明确末尾信号的结果可解释，不误报完整。
- [ ] 回收站彻底清理及共享文件保护、空间统计、下载范围/容量控制。
- [ ] 在独立环境完成元数据恢复，验证媒体路径和继续同步；媒体需另外备份。
